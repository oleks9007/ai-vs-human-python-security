# Security of AI-Generated Versus Human-Written Python Code: A Controlled Replication

Supplementary material (reproducibility package) for the paper by **Oleksii Voloshyn**, Vistula University,
Architecture of Computers (CII3SE003CI), Student Research Challenge 2026/27.

The study compares 20 security-relevant Python tasks (10 CWE categories x 2 tasks). For every task there is one
solution generated by ChatGPT (web version, first answer, prompt without security wording) and one human-written
solution taken from Stack Overflow (accepted or highest-voted answer published before 30 November 2022, minimally adapted).

## Repository structure

| Path | Content |
|---|---|
| `PROMPTS.md` | Exact ChatGPT prompts for every task and the planned Stack Overflow questions |
| `solutions/ai/taskNN.py` | AI-generated solutions (copied unchanged from the first ChatGPT answer) |
| `solutions/human/taskNN.py` | Human-written solutions (Stack Overflow answers, minimally adapted; see the research log) |
| `tests/` | Functional tests (3 per task, pytest); external services (HTTP, MySQL) are replaced by fakes |
| `blind/S01.py ... S40.py` | Anonymised copies reviewed blind; the mapping is in the `Key` sheet of the research log |
| `research_log_20.xlsx` | Research log: `Tasks` (sources, links, dates, revisions, every adaptation), `Results` (per solution), `Pairs`, `Summary`, `Key` |
| `results/bandit.csv`, `results/semgrep.json` | Raw scanner output |
| `results/manual_review_final.xlsx` | Review protocol, verdict and justification for every scanner warning, manual checklist for all 40 files |
| `results/rater2.json`, `rater2_protocol.txt`, `reliability_check.md` | Independent second rating and agreement |
| `results/statistics.md` | Summary of the reported numbers |
| `scripts/make_pack.py` | Generated the tests and `PROMPTS.md` |
| `scripts/make_blind.py` | Created the blinded copies from the `Key` sheet |
| `scripts/compute_stats.py` | Recomputes the reported numbers and exact tests from the research log |

## How to reproduce

Tested with Python 3.13.17 on Windows.

```
pip install -r requirements.txt
python -m pytest tests -v                      # functional tests
python -m bandit -r blind -f csv -o results/bandit.csv
semgrep --config p/python blind --json -o results/semgrep.json
python scripts/compute_stats.py               # numbers reported in the paper
```

Expected test result on Windows: 119 passed, 1 failed (`test_task20.py::test_overwrite[human]`; the human T20
solution appends to its cache file, so task T20 is excluded from the comparison). Task T05 (`ping`) uses Windows
`ping` options as required by its prompt, so its tests fail on Linux/macOS.

## Notes and limitations

- The review decisions were drafted with AI assistance (Claude) under the written protocol and approved by the author;
  the second rater was a separate AI instance. See the paper's AI declaration.
- Blinding was partial: the author saw every solution while collecting it.
- Semgrep was run without an account (no Pro rules).
- Passwords, keys and database credentials in the solutions are placeholders or example values copied from the
  original sources; none of them is a real credential.
